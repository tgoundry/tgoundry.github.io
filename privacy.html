Privacy Policy - Personal Mail Copy

Personal Mail Copy is used only by its owner, for the owner's own accounts. It uses only the Gmail API scope gmail.insert, which can add messages to the owner's Gmail account and cannot read, change or delete Gmail data. No data is collected, shared, sold, used for advertising, or used to train machine-learning models. The owner can revoke access at any time from the Google Account permissions page.
