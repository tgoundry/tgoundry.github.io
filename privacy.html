Privacy Policy - Personal Mail Copy

Last updated: October 22, 2026

Personal Mail Copy is a personal, single-user application operated by its owner for the owner's own use only. It has no other users.

What the application does

It reads email from the owner's own mailbox, inserts copies of those messages into the owner's own Gmail account, and keeps a small local list of message identifiers on the owner's own computer so that the same message is not inserted twice.

Google permission used

The application uses the Google Gmail API scope https://www.googleapis.com/auth/gmail.insert only. This scope lets the application add messages to the owner's Gmail account. It does not let the application read, search, change or delete any message or other data in the Gmail account.

Data handling

The application does not read Gmail data. Message content is sent only to Google's Gmail API, for the owner's own account, and nowhere else. The application does not collect, sell or share Gmail data or other personal information with any third party, does not use any data for advertising, and does not use any data to develop or train machine-learning models.

Credentials

Credentials used by the application are stored on the owner's own systems and are not transmitted to any third party other than Google, for sign-in and for the Gmail API calls described above.

Revoking access

The owner can revoke the application's access at any time from the Google Account permissions page, and can stop the application by turning it off.
